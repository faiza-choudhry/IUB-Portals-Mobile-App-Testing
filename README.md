## Project Overview

This project focuses on the manual Quality Assurance (QA) testing of the **IUB Portals mobile application**.

The purpose of this testing was to evaluate the application's functionality, user interface, usability, navigation, and overall user experience from an end-user perspective.

The testing process involved examining different application features, identifying potential usability and functional issues, and documenting test cases and observations.
